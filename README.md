## Overview

HENOK Art Studio is a visual artist portfolio website concept created to present artistic work through an expressive and immersive digital experience.

The project focuses on showcasing paintings, murals, drawings, and creative commissions with an editorial visual direction, spacious layouts, and strong artwork imagery.

The website is designed to give the artwork a central role while introducing the artist and providing a way for visitors to make project enquiries.

## Design Direction

The visual identity follows a contemporary art-studio aesthetic, combining cinematic imagery, editorial typography, and contrasting section layouts.

### Design Principles

- Artwork-focused presentation
- Cinematic hero composition
- Editorial serif typography
- Spacious gallery layouts
- Intentional contrast between light and dark sections
- Responsive layouts for desktop, tablet, and mobile

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/belaaa27/henok-art-studio.git
```

### 2. Navigate to the project directory

```bash
cd henok-art-studio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```
